Configurazione Supabase

SQL da eseguire su Supabase
Supabase → SQL Editor → New query → incolla → Run
Istruzioni (5 minuti):
1. Vai su supabase.com → crea account → New Project
2. SQL Editor → New query → incolla il SQL qui sopra → Run
3. Settings → API → copia Project URL e anon key
4. Incolla nei campi qui sopra → Salva e Attiva → Testa Connessione
5. Sincronizza Utenti → fatto!
